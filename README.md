# 🌦️ Weather App

A responsive weather application that allows users to search for a city and view current weather information.

## 🚀 Features

* Search for weather by city
* Displays current temperature
* Shows weather conditions
* 5-day forecast
* Displays additional weather information
* Responsive design for desktop and mobile devices
* Handles invalid or unavailable locations

## 🛠️ Technologies

* HTML5
* CSS3
* JavaScript
* TypeScript
* OpenWeather API
